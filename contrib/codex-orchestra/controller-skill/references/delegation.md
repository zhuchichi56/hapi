# 放权清单

目标:**尽量减少需要用户的次数**。总控遇到要决定的事,先查这张表:命中"可自行决定"就自己定、记账、事后告知;没命中且属 D2 才问用户。

**谁来做这些决定:** D0 默认交项目审查;还没有项目审查时 Root 兼任;已有项目审查时 Root 只负责路由与终审,不并行重做同一个决定。下表只回答"能不能不问用户",不规定由哪一层做。

规则:
- **只收用户明确说过的。** 每条标来源。总控不得自行扩权,也不得把"没问过"当成"可以"。
- 新放权:用户一句话即可追加("这类以后你自己定")。总控把它写进本表并注明日期和原话要点。
- 收回放权同样一句话。冻结协议、用户指定的配方与参数不在放权范围内,任何情况下偏离都要先停下列差距。
- 自行决定的事:先写一条 `decision`(authority=controller,含理由),事后合并进页面"决定记录";不单独打扰用户。

## A. 总控可以自行决定(命中就定,事后告知)

| 事项 | 范围与边界 | 来源 |
|---|---|---|
| 常规设计、实现细节、排障路径 | 在已批准目标与授权内 | Skill 2026-11-02 "决策分流" |
| 证据核对、是否返工、调查交接是否验收 | 满足合同就验收;有缺项自行定位并找原负责人纠偏 | 同上 |
| 受阻时排障、修接入、换可行实现 | 仅在现有授权内;不扩大权限、不增加费用 | Skill 2026-11-02 "快速接单" |
| 未派任务及时派出;依赖不足先推进独立部分 | 按已登记目标;不超同一 Agent 3 个独立任务 | 同上 + Skill 2026-11-03 |
| 选择执行者与模型 | 简单明确用 DSH + DeepSeek V4.1 Flash,复杂/疑难用 Codex + GPT-6.1 Sol;用户指定的优先;冻结实验不换 | AGENTS.md 默认分工 |
| 同一目标的新阶段、续查、换聊天 | 按"原聊天优先、独立目标另建"判断,记录新旧 ID 与理由 | Skill "原对话延续" |
| 内部 Sub Agent 并行核验 | 只读;不改线上服务;不替代 Root 终审 | Skill 2026-11-02 "内部并行核验" |
| 授权范围内的常规"同意"、必要验证、已核实的真实性声明 | 由执行者自行处理;缺关键事实或范围外新承诺才问 | AGENTS.md 授权章节 |
| 已批准设置的直接执行、续跑、小规模验证 | 不改冻结科学设置 | AGENTS.md 实验章节 |
| 清理已确认可再生成的产物、缓存和本次临时文件 | 用户原创文件或不可再生成的数据先备份 | AGENTS.md 文件保护 |
| 工作聊天向后台收件回执 | 不得发到总控聊天 | Skill 2026-11-02/03 |
| 任务验收(不含归档) | 对照合同核对产物与关键数字 | Skill 2026-11-02 |

## B. 必须问用户(D2,不可放权,除非用户逐类明确说)

| 事项 | 备注 |
|---|---|
| **归档**(默认) | 每次用户明确确认,多个待归档合并成一条问。**可按类别放权**:用户明确说"某类已验收的以后自己归档"后,在登记的范围内可自行归档,条件见 [验收与归档](review-archive.md) §4 |
| 缺失关键意图,或存在实质取舍且无法从已知偏好推断 | 附推荐、收益、代价 |
| 增加未授权的支出、对外发送/公开发布 | 宣传文章逐篇先审后发 |
| 不可逆删除重要数据 | |
| 改变冻结协议、模型、预算硬截止、用户指定的配方与参数 | 先给逐项对齐表与差距,由用户决定 |
| 工具明确要求"本人当次确认/认证"的步骤 | 不得代答 |
| 向任何 `master` 推送 | 仅两个既有授权例外(见 AGENTS.md 分支保护) |
