用户明确提出过的呈现偏好和服务限制。改任务总控页面前先读本文件,并**比对原界面与最终截图**:技术测试通过不等于用户要求的最小变化已做到。

## 页面

- 打开 [任务总控](https://desktop.urbanclaw.net/desktop?app=codex&view=orchestra)。网页只读,现有 owner 登录生效。
- **Task 是主体,对话是次级详情。** 保留原任务队列的布局、视觉、交互;只增加"当前实际 Task 的节点关系树",默认折叠。不把全部历史项目、对话叶子、诊断、管理信息堆到主界面。旧的"项目→方向→任务→聊天"全量树已被用户否决,仅留历史。
- 真实执行中的任务置顶,其后排队和具体受阻项。已关闭/已结束阶段进入历史并默认折叠;未达标写清"本阶段结束,哪些仍未做好"。不因 review rejected 或归档回执缺失永久显示"需处理"。
- "待用户决定"只用于存在明确问题且确需用户决定的事项;内部待验收由总控及时消化。正文不展示模型、权限、旧预算、过期检查点等内部派工信息。
- 系统运行视图单列,与任务表分开:真实 token 投入及覆盖、派发/承接/交付/验收时延、停滞与审批等待、失败/重试/重复、质量、采集新鲜度。缺测写未知,不造 0;不把原生 completed/归档当目标完成,不把陈旧心跳直接当卡死。
- 详情极简:目标、结论、成果、下一步、投入;技术记录折叠。不堆授权原文、空字段、内部状态、重复日志。
- 页面刷新要让用户即时看到派发和状态变化,但不能把后台采样周期说成"用户即时可见";端到端时延以真实页面为准。

## 汇报

- 对用户默认表格:`成果｜进度｜做到哪了`。✅ 已完成且核验;⌛️ 未完成(写清是在执行、排队,还是阶段已结束);⚠️ 具体受阻或需用户决定。给一个直接成果链接、样稿或一张图,说清实际效果与缺口。未完成的不能标 ✅。
- 每项工作结束给简短交付报告:要求什么 → 实际做了什么、做完没有 → 一张图/一个例子/结果链接 → 验收结论。缺项具体写。少内部术语;不以长交接、测试数量或派单回执代替用户可看的结果。
- 正常、无变化、不可行动的情况保持静默。不逐条播报派单、承接、ACK、测试过程和内部验收记录。
- 聊天回复少解释,直接说改动和结果。
- **简报(`brief`)怎么写**(页面详情直接显示它,读的人看一眼就要懂):**≤2 句、≤80 字**。第一句只写结论——做完没有、得到什么;第二句才写数字或下一步。不写过程("我会…""接下来…""正在…")、不写内部词(collector、适配器、契约、回合、覆盖口径)、不加括号解释。数字写具体值,没有就写"未采集"。页面主区只显示第一句,其余折叠。

## 服务与限制

- 运行说明和验收见 `outputs/总控系统实现/README.md`、`实现与验收.md`。程序 `~/.local/lib/codex-orchestra/install.py` 支持 `status/start/stop/restart`,加 `--mini-tunnel` 同时管理专用 Mini 私有 socket 转发。停止它不停止工作聊天、不丢账本;恢复后先对账,不重新派发。
- 采集程序约每 5 秒读取本总控登记且未归档的聊天,只提取公开 assistant 进展、明确 turn 状态和工具状态,不保存用户/工具输出/推理原文。`idle`/`notLoaded` 不能证明完成;原生 latest turn 明确 `completed` 才算回报。5 秒是展示刷新,**不是模型巡检,也不是事件直通**。
- 原生状态桥是 Desktop 内部协议,可能随 App 升级变化;故障时显示过期并修适配器,不写 Codex 私有数据库、不启动第二执行器抢占原聊天。当前只支持本机 local Codex。没有验证手机通知、采集事件自动直通总控,也没有验证总控模型的 10 秒接单时延;前台短回合、后台确定性采集和程序并发测试不能代替这些证据。
- Codex 一侧的桥接走私有 IPC 套接字,代码里没有界面操作;连接 Claude 桌面端的一段使用辅助功能,会 `activate` 并发键盘事件,**必然抢前台焦点**。因此任何自动唤醒都不得经 Claude 桌面端;Codex 唤醒是否抢焦点需实测后才能声称无影响。

## Session 数量

工作 Session 管理目标上限为 10,独立任务可并行;这不是长上下文或持续 10 Agent 的容量验收。`WORKER_COUNT=4` 只表示采集并发。待办任务数与实际运行 Session 数分别显示;排队只写已核实的原因(未派、依赖、共享资源、线路限流)。多 Session 收尾须逐分工核对验收与剩余职责,不因一个 Session 完成就验收或归档整个任务。逐 Session 原生归档尚未实现,不绕过保护。
