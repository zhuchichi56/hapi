## 当前边界

- 公网静态资源传输仍不稳定。补充外网探针中，首页一次在 5.851 秒完整返回；紧随其后的静态资源请求在 TLS 完成前 25 秒超时，尚未进入应用服务。原站静态资源已配置一年 immutable 缓存；本轮没有据此猜改 Cloudflare 路由。本轮隔离浏览器验收时，部分 JS／CSS 通过既有 SSH 提供与生产构建逐字相同的资源；认证和原生 API 仍使用公网 HTTPS。因此图片、排版和交互验收有效，但不能据此宣称公网首次加载速度通过。
- 真实原生待回答／审批和真实 iOS 键盘仍需相应现场，不能把 fixture 或缩短浏览器高度当作端到端验收。
- Claude 原生写操作需要 Mac 解锁，可能切换原桌面选中的会话；后台读取保持被动。未确认的后台状态保持未知，不虚构黄色／蓝色状态。
- 未接入原生重命名、远程本机文件打开／下载、进程冻结后恢复。已有“停止”结束原当前轮并保留对话。
- 两台 Mac、原 App、电源和现有网络通道仍须可用；未宣称合盖休眠或整机重启可用。
