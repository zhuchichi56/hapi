## 已上线

历史能读取但不能发送的原因是原会话没有加载到桌面执行通道。显式发送现在会自动打开同一个原 thread，重新订阅原 owner，再发送一次；模型和强度从原 App 继承。加载失败明确标记未发送、保留草稿；不确定写入不会自动重放。普通读取不移动桌面选择。

Claude 选择题从原 transcript 的 AskUserQuestion tool ID 和输入生成请求。网页答案提交时重新匹配原会话、原问题和实际选项，读取真实勾选状态，并只点击原 Submit 一次；以原 transcript 的回执确认结果。原 App 的 AXPress/Space 曾返回成功却未提交，现使用经过实际控件定位和命中校验的指针点击。激活和勾选可能重排 AX 树，因此每次重新定位。单题后台仍可见，多页只处理当前能够准确匹配的原生页；不伪造其他按钮或把回复文字当作原生回答。

已结束轮次折叠公开进展及工具，按需挂载详情并显示真实用时；最终回答保持展开，内部 reasoning 继续排除。文件变更在本轮结束后统一出现一份，按路径合并；点“查看更改”才读取原始差异，首批最多八条修改记录，更多手动加载。增删行数是各次原生 diff 的累计，未提供时不编造，不能当作最终 Git 净差异。
