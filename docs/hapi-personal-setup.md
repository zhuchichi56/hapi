# 当前 HAPI 的版本与设置说明

核对日期：2026-10-04。当前 Hub 与本机 Runner 使用同一份 **0.30.7 源码定制构建**，前端另有本机定制。GitHub 当前最新正式 Release 也为 0.30.7。

## 本机这次的界面调整

- 输入框的常用按钮贴近底部，单行输入时不再在按钮下方空出一行。
- 侧边栏的“New Session”直接创建 **Codex / GPT-6.1-Sol / Medium** 会话，不再先选 Agent、模型和推理强度。
- 默认在本机用户目录工作；项目菜单中的“新会话”沿用该项目目录。
- 创建前检查指定机器、模型档位和目录；失败会提示，重试仍使用相同目标。
- 权限沿用这台机器保存的 Codex 权限偏好；没有偏好时使用默认权限。
- 需要导入历史会话或手动配置时，原创建表单仍可通过 `/sessions/new` 访问。

## 最近版本大概更新了什么

先前 Hub 为 0.29.0，CLI 为 0.27.3；此前升级已统一到 0.30.7。本轮没有再次提高版本号；实际创建验证发现全局安装版 Runner 与定制 Hub 的新会话协议不一致，已让 Runner 使用 Hub 的同一构建。下面是上游发布说明中的主要变化，不包含本机定制的 Work 界面。

| 版本 | 与日常使用有关的变化 |
| --- | --- |
| [0.29.1](https://github.com/tiann/hapi/releases/tag/v0.29.1) | 发布说明汇总了 Codex/Cursor 运行中追加引导、Codex MCP 配置、会话标未读/全部已读、附件拖动排序、回到底部按钮、每轮 Token 用量、文件预览换行，以及流式输出、队列、回退和侧栏滚动修复。 |
| [0.30.3](https://github.com/tiann/hapi/releases/tag/v0.30.3) | 修复取消/编辑排队消息后，处于不确定状态的行仍留在界面的问题。 |
| [0.30.4](https://github.com/tiann/hapi/releases/tag/v0.30.4) | 修复 Android API 36 下工具组详情的稳定性；对当前 Mac Web 界面影响较小。 |
| [0.30.6](https://github.com/tiann/hapi/releases/tag/v0.30.6) | 改进侧栏搜索排序、历史长会话的初始加载、搜索后的置顶分隔线，以及 Markdown/导出中的 LaTeX 支持。 |
| [0.30.7](https://github.com/tiann/hapi/releases/tag/v0.30.7) | 支持 macOS 27；切换会话时保留 AskUserQuestion 的未提交答案；未读徽标只统计符合侧栏显示条件的会话。 |

0.30.1 的发布页没有列出详细变化；0.30.2 主要修复 Hub 测试隔离。它们不是本轮界面修改的重点。

## Settings 应该看哪些

Settings 主要管理 HAPI 的界面、交互、连接和统计。模型、推理强度、权限可在会话输入框附近调整；本机一键新会话的默认模型已固定。

| 页面 | 用途 | 当前建议 |
| --- | --- | --- |
| General / 常规 | 语言、会话状态摘要、原生客户端配对 | 先确认语言。状态摘要默认关闭即可；需要通知摘要时再开。不用手机原生 App 时可跳过配对。 |
| Display / 显示 | 明暗主题、字体大小、侧栏状态、会话头元数据、外部链接行为 | 最值得看。选择舒服的字号与主题；可减少头部元数据，让聊天页更简洁。 |
| Chat / 聊天 | 回车发送或换行、工具卡片详细度、工具组和思考默认折叠、消息背景色 | 最值得看。建议工具卡片用简洁模式，探索工具组和思考默认折叠；回车行为按个人习惯。精简输入区的次要工具仍收在“＋”里。 |
| Machines / 机器 | 查看机器连接、名称和 Runner 状态 | 连不上或创建会话失败时查看；平常无需反复调整。不要把旧机器记录当成当前可用连接。 |
| Voice / 语音 | 语音输入、语音助手及相关音频选项 | 经常语音输入时再配置；只打字可跳过。 |
| Storage / 存储 | 查看 Hub SQLite 数据库、WAL、SHM 的磁盘占用 | 只在占用增长或排查存储问题时查看；不是模型文件或项目文件的清理入口。 |
| Usage / 用量 | HAPI 管理期间的 Token 使用情况和分布 | 想了解使用量时查看；不包含导入前的历史用量，也不是服务商账单或剩余额度。 |
| About / 关于 | 版本和项目信息 | 升级或排查版本差异时查看。 |

以上是建议，没有自动修改你的 Settings 偏好。
